Developed a desktop-based AI chatbot using Python and the Gemini API, featuring an interactive graphical user interface and real-time conversational capabilities. The application provides human-like responses, maintains conversation context, and ensures a smooth user experience through efficient design and asynchronous processing.

Designed a modern chatbot interface using Tkinter with styled chat bubbles and bot avatar
Integrated Gemini API to generate intelligent, context-aware responses
Implemented persistent memory using JSON to store and reload chat history across sessions
Used multithreading to handle API calls without affecting UI responsiveness
Added typing indicators to simulate real-time conversation flow
Incorporated error handling for stable and reliable performance
